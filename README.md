## Files Included
- `books.json` — Structured JSON dataset of books.
- `books.html` — Fetches and safely renders data from `books.json` using native `fetch()` and DOM methods.
- `jquery-dom.html` — Demonstrates DOM manipulation and event handling using jQuery 4.0.0.

## Setup Instructions
1. Open this project folder in **Visual Studio Code**.
2. Right-click `books.html` and select **Open with Live Server** (required so `fetch()` works over HTTP rather than `file://`).
3. Open `jquery-dom.html` via Live Server or directly in a modern browser.
